StrideSense — interactive 3D product concept

Contents
- gait_device_3d_viewer.html: interactive 3D product viewer.

How to view
1. Extract this ZIP file.
2. Open gait_device_3d_viewer.html in a modern browser while connected to the internet.
3. Drag to rotate, scroll to zoom, and use Front / Side / Back / Orbit for preset views.
4. Use Cable routing to show or hide sensor wiring.

The viewer loads Three.js from jsDelivr, so an internet connection is required.
This is a concept visualization, not a manufacturing CAD model or a clinical measurement tool.
